=== APPLICATION TITLE ===
Hire Downloader

=== SHORT DESCRIPTION ===
Hire Downloader is a fast, lightweight, open-source Windows media downloader. Grab videos from Facebook, Instagram, TikTok, Twitter/X, Twitch, Vimeo, SoundCloud, Dailymotion, Reddit, and 1000+ other sites, plus direct file downloads — with a sleek dark UI and no ads.

=== LONG DESCRIPTION ===
Hire Downloader is a free, lightweight Windows application built with Python and Edge WebView2 that lets you download videos and media from Facebook, Instagram, TikTok, Twitter/X, Vimeo, Reddit, Twitch, Dailymotion, SoundCloud, and over 1000 other supported websites. It uses the powerful yt-dlp library (as a Python library, not a slower subprocess) for maximum site compatibility, so new sites and formats are supported continuously.

The app also handles direct HTTP file downloads with resume support, making it a one-stop tool for media fans, marketers, content creators, students, and anyone who wants to keep media offline. Choose video quality (up to HD/4K where available) from an in-app quality picker, queue multiple downloads, and reorder with pause/resume/cancel controls.

The modern dark interface keeps everything readable and fast: paste a URL, pick quality, and download. Download history lets you re-add anything instantly. Automatic updates are built in — the app checks GitHub for new versions and verifies installer integrity (SHA-256 where published, plus Authenticode signature checks) before updating, so you always run a secure, current build.

Key benefits and capabilities:
- Social media downloads: Facebook, Instagram, TikTok, Twitter/X, Twitch, Vimeo, SoundCloud, Dailymotion, Reddit, and 1000+ more via yt-dlp.
- Direct file downloads with resume and range support.
- Quality selector with resolution options where available.
- Download queue with configurable concurrency (1–10) plus pause/resume/cancel.
- Persistent download history with one-click re-add.
- Automatic GitHub-based updates with verified installer integrity.
- Dual-architecture support for 32-bit and 64-bit Windows 10/11.
- Sleek dark UI, lightweight (~20 MB), no ads, no bloatware, fully open source.

Hire Downloader solves the everyday problem of saving videos from sites that make downloading difficult — fast, securely, and free.
