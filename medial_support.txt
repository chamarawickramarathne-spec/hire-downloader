1. TITLE
Hire Downloader

2. SHORT DESCRIPTION
Lightweight Python Windows downloader for YouTube, playlists, torrents, and direct files — powered by pywebview, yt-dlp, and aria2c. 32-bit & 64-bit.

3. LONG DESCRIPTION
Hire Downloader 3.0 is a complete rewrite using pywebview with Edge WebView2 for a native-feeling dark UI and dramatically smaller footprint. Download YouTube videos and playlists with quality choice, magnet torrents via aria2c, and direct HTTP files with resume. Manage a concurrent download queue, pause and resume jobs, schedule overnight downloads, and keep a local history. Built-in updates install the correct 32-bit or 64-bit setup from GitHub automatically.
